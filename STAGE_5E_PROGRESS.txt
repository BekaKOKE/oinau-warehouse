==================================================
ФОРМАТ
==================================================
Листы: Products, Prices, ProductAttributes, ProductSpecs, Categories,
CategoryAttributes, Attributes, AttributeOptions (+ README).
Ключи: товар — sku, категория — slug, характеристика — code,
вариант — attribute_code + slug. Внутренних id/UUID в файле нет.
Сущности создаются/обновляются и никогда не удаляются; связи сущностей из
файла (категории, цены, характеристики, specs, фильтры категорий)
заменяются целиком; всё, чего нет в файле, не трогается. Первая категория —
основная. Неизменённые данные не пишутся (без updated_at и аудита).
Экспорт -> импорт без правок = ноль изменений (тест сравнивает весь каталог).
SKU неизменяем: новый артикул = новый товар; «переименование» упирается в
занятый slug. Остатков в формате нет. Подробно: docs/api-catalog-import-export.md

==================================================
БЕЗОПАСНОСТЬ
==================================================
Тип по содержимому (ZIP + [Content_Types] + main part), отказ .xls/CSV/
.xlsm/шифрованных; лимит размера UPLOAD_MAX_SIZE_MB по мере чтения тела;
ZIP-бомба и опасные пути; defusedxml (XXE, billion laughs — тесты);
формулы, ошибки Excel и даты не принимаются; HTML и управляющие символы
отвергаются; экспорт — строки только типом s + quotePrefix для = + - @
(значение не искажается); имя файла очищается; содержимое файла не
пишется ни в журнал, ни в историю.

==================================================
ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ
==================================================
- Подтверждение синхронное (для текущего размера каталога — доли секунды);
  перенос в воркер не меняет контракт. Отмечено в docs/architecture.md
  как уточнение принципа 3.
- На подтверждение файл отправляется повторно: сервер его не хранит.
- Цены — только публичный прайс-лист по умолчанию.
- Не через Excel: остатки, изображения, stock_display_override, weight_kg,
  переименование sku / slug категории / кода характеристики, удаление и
  восстановление сущностей.
- Обмен slug или external_id между двумя товарами в одном файле
  отклоняется — выполняется в два импорта.
- Тексты с HTML, уже сохранённые через Admin API, импорт не примет
  (экспорт их выгрузит, предпросмотр покажет ошибку).
- Предпросмотр доступен ролям с catalog.read (в т.ч. MANAGER): так задано
  требованиями этапа; каталог он не меняет.

Следующий этап не начинался (frontend / Telegram / Email / WhatsApp / 1С).
