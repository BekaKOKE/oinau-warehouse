# ADR-0003. Изображения — только во внешнем Object Storage

**Статус:** Принято
**Дата:** 2026-09-09

## Контекст

Изображения товаров (2–4 фото плюс схемы на позицию) можно хранить на диске
приложения или в репозитории. Оба варианта отвергнуты.

## Решение

Cloudflare R2 + CDN на `cdn.oinau-pro.kz`. Локально — MinIO с тем же S3 API.
В PostgreSQL хранится только `storage_key`. Загрузка из админки идёт напрямую
в хранилище по presigned URL, минуя FastAPI.

## Обоснование

- Файлы в Git раздувают репозиторий и замедляют деплой.
- Диск приложения ломает горизонтальное масштабирование и теряется при откате.
- Раздача картинок через FastAPI занимает воркеры, нужные для API: одна
  страница каталога — это 20+ запросов за изображениями.
- У R2 нулевая плата за исходящий трафик, что решающе для каталога.
- Хранение `storage_key` вместо URL делает смену CDN правкой переменной
  окружения, а не массовым `UPDATE`.

## Последствия

Нужен воркер для генерации вариантов (`large`/`medium`/`small`/`thumb`) либо
трансформации на стороне CDN. Схема `media_files.variants` (JSONB) поддерживает
оба варианта; выбор делается на этапе 6.
