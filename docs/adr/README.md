# Architecture Decision Records

Короткие записи о принятых архитектурных решениях: что решили, почему,
какие альтернативы отвергли.

Через полгода никто не вспомнит, почему выбрана гибридная модель атрибутов
или почему админка вынесена в отдельное приложение. ADR экономят месяцы
повторных споров и защищают от «улучшений», ломающих исходные ограничения.

Формат имени: `NNNN-краткое-название.md`.
Статусы: `Предложено` → `Принято` → (`Заменено ADR-NNNN` / `Отменено`).
